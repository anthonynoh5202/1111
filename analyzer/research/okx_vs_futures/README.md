# OKX·Bybit 시세로 신호를 대신 계산해도 되나 (2026-11-18)

Anthropic 클라우드에서 바이낸스 선물 API는 위치 제한으로 막힌다. 다른 거래소의 무기한 선물 시세를 시험했다.

| 거래소 | 클라우드에서 읽히나 |
|---|---|
| Bybit (`api.bybit.com`) | 안 됨. HTTP 403, 국가 차단 |
| OKX (`www.okx.com`) | 됨. 공개 API, 키 없음 |

OKX `BTC-USDT-SWAP` 4시간봉(2020-01~2026-11, 15,099개, 봉 시작 시각이 바이낸스와 같음)으로 신호를 계산해 바이낸스 선물 신호와 대조했다.
기준값은 고정, 수익은 바이낸스 선물 종가 16시간 뒤, 비용 전.

| 기간 | 봉 | 바이낸스 롱 중 OKX도 롱 | 바이낸스 신호 초과 수익 | OKX 신호 초과 수익 |
|---|---|---|---|---|
| 2020~2023 (기준을 정한 기간) | 8,745 | 88% | +0.146%p (t 2.23) | +0.143%p (t 2.10) |
| 2024-01~2026-09 (확인 기간) | 6,012 | 91% | +0.181%p (t 2.98) | +0.106%p (t 1.79) |
| 2026-09-29~11-16 (처음 보는 자료) | 290 | 96% | −0.122%p (t −0.65) | −0.037%p (t −0.19) |
| 밤 9시 마감 봉만, 2024-01 이후 | 1,050 | 87% | +0.436%p (t 2.40) | +0.130%p (t 0.78) |

- OKX는 현물보다 바이낸스 선물에 가깝다(거래량 배수 상관 0.962, 현물은 0.935). 롱 신호 10번 중 9번이 같다.
- 그래도 확인 기간의 초과 수익은 바이낸스의 60%쯤이고 t 1.79로 우리 기준(2)을 넘지 못한다. 밤 9시 봉만 보면 더 약하다.
- 신호의 9%만 달라졌는데 초과 수익이 40% 줄었다. 엇갈린 봉은 양쪽 100개 남짓이라 우연일 수 있지만, 이 신호가 작은 자료 차이에 민감하다는 뜻이기도 하다.
- 결론: OKX 신호는 바이낸스 신호의 **미리보기**(약 90% 일치)로는 쓸 수 있다. 판정과 기록의 기준 자료로는 쓰지 않는다.
- 참고(사후 점검): 경계를 OKX의 2020~2023 상위 20%(0.4154)로 다시 잡아도 확인 기간 초과 수익은 +0.112%p (t 1.92)로 비슷했다.

재현:

```
python3 -I okx_dl.py okx_4h.csv
python3 -I okx_vs_fut.py okx_4h.csv <바이낸스 선물 일별 zip 폴더> <BTCUSDT_4h.csv.gz> out.json
```
