# 현물 시세로 신호를 대신 계산해도 되나 (2026-11-18)

Anthropic 클라우드에서는 바이낸스 선물 API(`fapi.binance.com`)가 위치 제한(HTTP 451)으로 막힌다.
현물 공개 API(`data-api.binance.vision`)와 과거 자료 보관소(`data.binance.vision`)는 읽힌다.
그래서 현물 4시간봉으로 계산한 "거래량 터진 윗꼬리" 신호가 선물 신호와 같은지 대조했다. 기준값은 고정, 수익은 선물 종가 16시간 뒤, 비용 전.

| 기간 | 봉 | 선물 롱 중 현물도 롱 | 선물 신호 초과 수익 | 현물 신호 초과 수익 |
|---|---|---|---|---|
| 2020~2023 (기준을 정한 기간) | 8,741 | 86% | +0.145%p (t 2.20) | +0.117%p (t 1.75) |
| 2024-01~2026-09 (확인 기간) | 6,012 | 88% | +0.181%p (t 2.98) | +0.083%p (t 1.30) |
| 2026-09-29~11-16 (처음 보는 자료) | 290 | 88% | −0.122%p (t −0.65) | −0.257%p (t −1.35) |

- 신호의 87%쯤은 같지만, 현물 신호의 초과 수익은 확인 기간에 선물의 절반 아래이고 우연과 구분되지 않는다. **현물은 신호 판정의 대체 자료로 쓸 수 없다.**
- 윗꼬리 비율은 거의 같다(상관 0.993). 차이는 거래량 배수에서 난다(상관 0.935). 종가 차이는 중앙값 0.046%라, 크기 상태와 차트 구조에는 현물을 써도 된다.
- 처음 보는 자료 290봉(롱 신호 52번)에서 선물 신호의 초과 수익은 −0.122%p였다. 이 기간 비트코인은 16시간마다 평균 −0.341% 내렸다. 표본이 작아 판정할 수 없고, 버리는 기준(t −1.5 아래)에는 닿지 않았다.

재현: 보관소에서 현물 월별·일별, 선물 일별 4시간봉 zip을 받아 폴더에 두고

```
python3 -I spot_vs_fut.py <현물 zip 폴더> <선물 zip 폴더> <BTCUSDT_4h.csv.gz> out.json
```

한계: 선물 과거 자료는 `claude/funny-bell-8fkiag` 브랜치의 `data/binance/BTCUSDT_4h.csv.gz`(2026-09-28까지)에 보관소 자료(2026-11-16까지)를 이어 붙였다. 선물 보관소는 하루 이틀 늦게 올라온다.
