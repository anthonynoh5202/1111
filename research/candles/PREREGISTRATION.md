# 캔들 모양·거래량 검증 — 사전 등록 (2026-11-08, 결과를 보기 전에 고정)

질문: 캔들 하나하나의 **모양**(몸통·꼬리·종가 위치·크기)과 **거래량**(평소 대비 배수, 시장가 매수 비중)이 BTC의 다음 움직임 **방향**을 비용을 넘을 만큼 알려 주는가?
이름 붙은 패턴(망치형 등)은 다루지 않는다(사용자 요청: "패턴 말고 캔들의 모양, 거래량 등등").

## 자료와 기간
- 바이낸스 USDⓈ-M BTCUSDT 무기한선물 1시간·4시간·일봉(`data/binance/`, data.binance.vision), 2020-01-01 ~ 2026-09-28(UTC 봉).
- 학습 기간(IS): 2020-01-01 ~ 2023-12-31. 검증 기간(OOS): 2024-01-01 ~ 2026-09-28. 보유 기간이 경계를 넘는 경우는 뺀다. 앞쪽 30봉은 쓰지 않는다.

## 특징 13개 (봉 t가 마감된 뒤 알 수 있는 값만)
| 이름 | 뜻 | 계산 |
|---|---|---|
| body | 몸통 방향·비율 | (종가−시가)/(고가−저가) |
| upper | 윗꼬리 비율 | (고가−max(시가,종가))/(고가−저가) |
| lower | 아랫꼬리 비율 | (min(시가,종가)−저가)/(고가−저가) |
| close_pos | 봉 안에서 종가 위치 | (종가−저가)/(고가−저가) |
| size | 봉 크기(평소 대비) | (고가−저가)/직전 20봉 평균 |
| body_size | 장대양봉(+)·장대음봉(−) | (종가−시가)/직전 20봉 \|몸통\| 평균 |
| vol | 거래량 배수 | 거래량/직전 20봉 평균 |
| buy | 시장가 매수 비중 | 시장가 매수 체결량/거래량 |
| vol_dir | 거래량 실린 양봉(+)·음봉(−) | 부호(종가−시가) × vol |
| upper_vol | 거래량 터진 윗꼬리 | upper × vol |
| lower_vol | 거래량 터진 아랫꼬리 | lower × vol |
| pos20 | 최근 20봉 범위 안 위치 | (종가−20봉 최저)/(20봉 최고−20봉 최저) |
| ret5 | 최근 5봉 흐름 | ln(종가/5봉 전 종가) |

고가 = 저가인 봉은 비율 특징을 비운다.

## 측정
- 보유 1·4·12봉. 수익 = ln(h봉 뒤 종가 / 지금 종가). 겹치지 않게 h봉마다 하나씩만 센다(시작 위치 0).
- 시험 수: 특징 13 × 봉 3 × 보유 3 = 117개.
- **단일 특징 시험**: 학습 기간 값으로 5등분 경계를 정해 고정한다. 맨 위 20%와 맨 아래 20%의 평균 수익 차이(위 − 아래)를 본다. p는 Welch t 검정(정규 근사).
  - 판정 1 '발견': 학습 기간 양쪽 p에 Benjamini–Hochberg q = 0.10.
  - 판정 2 '확인': 발견된 것 중 검증 기간에도 차이의 부호가 같고 한쪽 p < 0.05.
  - 판정 3 '돈이 됨': 확인된 것 중, 검증 기간에 "좋은 쪽 20%면 그 방향으로, 나쁜 쪽 20%면 반대로" 매매한 거래 1번 평균 수익이 비용보다 큼. 비용은 시장가 왕복 0.14%(수수료 0.05%×2 + 미끄러짐 0.02%×2), 지정가 왕복 0.04%. 펀딩비는 넣지 않는다.
- **묶음 모델**: 봉·보유마다 13개 특징과 그 1·2봉 전 값(39개)을 학습 기간 기준으로 표준화한다. L2 로지스틱 회귀(λ = 1.0, 학습 기간 모든 봉)로 '오를 확률'을 낸다.
  - 검증 기간 AUC를 계산하고, 라벨을 섞어 200번 계산한 AUC의 95% 범위(우연 범위)와 비교한다.
  - 학습 기간 확률의 위 20% 경계 이상이면 롱, 아래 20% 이하면 숏으로 매매해 거래당 평균 수익(비용 전·후)을 본다.
- **대조(가짜 차트)**: 실제 봉의 모양(시가 대비 고가·저가·종가)·거래량·매수 체결량을 순서 없이 다시 뽑아 이은 가짜 차트 20개에 단일 특징 시험 전체를 돌린다. 우연만으로 '발견'·'확인'·'돈이 됨'이 몇 개 나오는지 센다.
- **참고 1(크기 예측)**: 검증 기간, 보유 1봉, 특징 size·vol의 맨 위 20%와 맨 아래 20%에서 다음 봉 |수익| 평균의 비율.
- **참고 2(손익분기 적중률)**: 0.5 + 비용 / (2 × 검증 기간 평균 |수익|). 이길 때와 질 때 크기가 같다고 가정한다.
