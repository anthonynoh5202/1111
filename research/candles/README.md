## 결과 요약
1. 사전 등록 판정(단일 특징 117개): 발견 4, 검증 기간 확인 4, 비용 뒤 플러스 1(4시간봉·16시간·거래량 터진 윗꼬리).
   가짜 차트 20개(같은 봉 모양을 순서만 섞음): 발견 평균 0.3(최대 4), 확인 0, 비용 뒤 플러스 0. → 정보가 0은 아니다.
2. 묶음 모델(특징 13개 + 1·2봉 전 값, 로지스틱 회귀)의 검증 기간 AUC: 1h 0.549/0.551/0.537, 4h 0.549/0.563/0.537, 1d 0.520/0.567/0.545(보유 1·4·12봉).
   라벨을 섞은 우연 범위를 넘은 것: 1h 3개, 4h 2개, 1d 1개(경계).
3. 방향 정보는 '단기 되돌림'이다. 종가가 봉 위쪽이거나 아랫꼬리가 긴 봉 뒤에는 약세, 윗꼬리가 긴 봉 뒤에는 강세였다. 흔한 해석과 반대다.
   거래량 실린 장대양봉/음봉, 시장가 매수 비중, 장대양봉/음봉 크기는 1h·4h·1d 모두 차이가 없었다.
4. 크기는 비용보다 작다(사후 점검, 검증 기간 모든 봉, 겹침 보정 t).
   - 1h: 거래당 +0.02%(t 3~4). 지정가 왕복 0.04%도 못 넘는다(지정가 뒤 t −4). 연도별로 2024 → 2026 줄어 거의 0이 됐다.
   - 4h·16시간: 거래당 +0.09%(t 1.6~2.2). 시장가 뒤 −0.05%. 지정가 뒤 +0.05%이지만 t 0.9~1.2로 우연과 구분되지 않는다.
   - 사전 기준을 통과한 1개는 겹치지 않게 세는 시작 위치에 따라 −0.05%~+0.18%로 흔들렸다. 모든 봉 기준으로는 시장가 뒤 −0.05%(t −1.2)였고, 2025년에는 손해였다.
5. 크기 예측은 뚜렷하다. 봉 크기·거래량 상위 20% 뒤 다음 봉의 움직임이 하위 20%의 1.3~1.8배였다.
6. 손익분기 적중률(시장가/지정가): 1h·1봉 71.4%/56.1%, 4h·4봉 54.9%/51.4%, 1d·4봉 52.0%/50.6%. 1h 모델의 상·하위 20% 적중률은 56.0%였다.
