# 실력 없는 트레이더 1만 명 모의실험 (생존 편향)

"돈 번 사람들은 캔들로 벌었다더라"는 말을 확인하려고 만든 계산이다. 실력이 0이어도 '크게 번 사람'이 얼마나 나오는지, 그 사람들이 다음 해에도 버는지 본다.

- 가정: 1년에 100번 거래, 매번 계좌의 5%를 손절 폭으로 건다. 이기면 +2R, 지면 -1R. 승률 0.32라 거래당 기대값 -0.04R(수수료 몫). 비교용으로 매번 10% 걸기, 실력 있음(승률 0.36, +0.08R)도 계산한다.
- 실행: `.venv/bin/python -I research/luck/luck_sim.py` (난수 시드 고정, 외부 자료 없음)
- 결과: `luck_sim_result.json`
- 한계: 거래 결과를 서로 독립인 동전 던지기로 단순화했다. 실제 시장은 연속 손실이 몰리는 등 더 거칠다.
