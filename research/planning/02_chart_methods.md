## 1. 핵심 요약 (5줄)

1. BTC를 대상으로 학술 근거가 가장 튼튼한 방법은 **느린 추세추종**(몇 주 단위의 시계열 모멘텀과 돈치안 채널)과 **거래량이 가진 정보**다. 캔들 패턴 이름, 엘리엇 파동, 피보나치, SMC/ICT, 와이코프는 인기에 비해 검증된 근거가 약하다. [2][4][11][15][16]
2. BTC의 1~4시간봉 수익률은 **되돌림(평균회귀) 경향**이 있다는 연구가 있다. 그래서 우리 기획의 "돌파 추격 금지, 되돌림에서 진입" 원칙은 방향이 맞다. [5][6]
3. 펀딩비, 미결제약정, CVD 같은 **선물 파생 데이터**는 단독 신호로는 약하다. 대신 **과열을 걸러 내는 필터**로는 쓸모가 있다. 바이낸스 캔들 데이터에 이미 들어 있는 "테이커 매수량"으로 CVD를 무료로 근사할 수 있다. [27][28][31]
4. 지형도에서 **워뇨띠**는 "선을 긋지 않는 가격행동 + 거래량 + 과거 닮은꼴(kNN류)"에 속한다. **차트프로**는 "와이코프/VSA + 매물대(볼륨 프로파일) + SMC의 50% 개념"을 한국식으로 바꾼 쪽에 가깝다. 두 방식에서 정의가 비어 있는 부분은 같은 계열에서 널리 쓰는 표준 정의(앵커드 VWAP, POC, 유동성 스윕)로 채워 백테스트할 수 있다.
5. 가장 크게 고칠 점은 Claude의 역할이다. 비전 LLM이 차트 이미지를 보고 방향을 맞힌 정확도는 **우연 수준이었고 롱 쪽으로 치우쳤다**. 과거 데이터로 LLM을 백테스트하면 **학습 데이터를 기억해서 성과가 부풀려진다**. 그래서 Claude에게는 코드가 계산한 숫자를 해석하는 일을 맡기고, "확신도 0.6"은 보정하기 전까지 확률로 쓰지 않으며, Claude의 성과는 **앞으로 쌓이는 페이퍼 트레이딩으로만** 평가한다. [39][40][41]

### 2.1 용어 풀이 (처음 보는 용어는 여기서 확인)

| 용어 | 한 줄 풀이 |
|---|---|
| 가격행동(Price Action) | 보조지표 없이 캔들 모양과 고점·저점 위치만으로 판단하는 방식 |
| 시장구조(Market Structure) | 고점과 저점이 높아지는지 낮아지는지의 순서. 고점·저점이 함께 높아지면 상승 구조 |
| 지지·저항 | 가격이 여러 번 멈추거나 되돌아간 가격대. 아래에서 받치면 지지, 위에서 누르면 저항 |
| SMC / ICT | "큰손(스마트머니)의 흔적"을 읽는다는 가격행동 학파. ICT는 창시자 Michael Huddleston의 활동명이다 [18] |
| 오더블록(OB) | 큰 움직임 직전의 마지막 반대색 캔들 구간. 큰손의 주문이 몰린 곳으로 본다 |
| FVG(Fair Value Gap) | 캔들 3개 중 1번 봉과 3번 봉 사이에 거래가 비어 있는 가격 구간 |
| 유동성 스윕(Liquidity Sweep) | 전고점·전저점 너머에 몰린 손절 주문을 꼬리로 한 번 쓸고 되돌아오는 움직임 |
| BOS / CHoCH | 기존 추세 방향으로 전고점(전저점)을 깨면 BOS, 반대 방향으로 깨면 CHoCH(추세 성격 전환) |
| 와이코프(Wyckoff) | 시장이 매집, 상승, 분산, 하락 국면을 돈다고 보고 거래량으로 국면을 판정하는 100년 된 방법 |
| VSA(Volume Spread Analysis) | 와이코프를 단순화한 것. 거래량(노력)과 캔들 폭(결과)을 비교한다 [19] |
| 볼륨 프로파일(VPVR) / 매물대 | 시간축이 아니라 **가격대별로** 거래량을 쌓아 보는 도구. 한국에서는 "매물대"라고 부른다 |
| POC / HVN / LVN | 거래량이 가장 많은 가격(POC) / 거래량이 많은 가격대(HVN) / 적은 가격대(LVN) [20] |
| VWAP / 앵커드 VWAP | 거래량으로 가중한 평균 가격. 앵커드 VWAP은 계산 시작점을 특정 봉(예: 거래량 급증 봉)에 고정한 것 |
| 엘리엇 파동 | 상승 5파, 조정 3파가 반복된다는 이론 |
| 피보나치 되돌림 | 직전 움직임의 38.2%, 50%, 61.8% 지점에서 되돌림이 멈춘다고 보는 도구 |
| 이치모쿠(일목균형표) | 전환선, 기준선, 구름대로 추세와 지지·저항을 한 번에 보는 일본식 지표 |
| MA 크로스 | 단기 이동평균이 장기 이동평균을 위로(골든크로스) 또는 아래로(데드크로스) 뚫는 신호 |
| RSI / MACD / 볼린저 밴드 | 과매수·과매도 지표 / 두 이동평균 차이로 추세 전환을 보는 지표 / 이동평균 ± 2표준편차 띠 |
| 슈퍼트렌드 | ATR(평균 변동폭)로 만든 추세 추적선. 가격이 선 위면 상승 추세로 본다 |
| 시계열 모멘텀(TSMOM) | "최근 N주 동안 올랐으면 계속 오른다"에 거는 추세추종 방식 |
| 돈치안 채널 | 최근 N일 최고가와 최저가로 만든 띠. 최고가를 넘으면 매수 신호 |
| 평균회귀 | 크게 움직인 가격이 평균 쪽으로 되돌아오는 성질 |
| 변동성 돌파 | 당일 시가 + 전일 변동폭 × k를 넘으면 사는 전략(래리 윌리엄스). 국내 코인 자동매매에서 유명하다 [26] |
| 펀딩비 | 무기한 선물 가격을 현물에 붙여 두려고 롱과 숏이 서로 주고받는 수수료. 양수면 롱이 숏에게 낸다 [27] |
| 미결제약정(OI) | 아직 청산되지 않고 열려 있는 선물 계약의 총량 |
| 청산 / 청산 히트맵 | 증거금이 부족해 강제로 정리되는 포지션 / 청산이 몰릴 것으로 **추정되는** 가격대를 색으로 그린 지도 |
| 롱숏비 | 롱 계정(또는 포지션)과 숏 계정의 비율 |
| 테이커 / 메이커 | 시장가로 즉시 체결시키는 쪽 / 지정가 주문을 걸어 두고 기다리는 쪽 |
| CVD / 오더플로 | 테이커 매수량에서 테이커 매도량을 뺀 값을 누적한 것 / 주문과 체결의 흐름을 직접 분석하는 방법 |
| 베이시스 | 선물 가격과 현물 가격의 차이(보통 연율 %). 선물이 비싸면 콘탱고, 싸면 백워데이션 |
| 온체인 / MVRV | 블록체인 기록을 분석하는 방법 / 시가총액을 실현가치(각 코인이 마지막으로 움직였을 때 가격의 합)로 나눈 값 |
| ETF 흐름 | 미국 현물 비트코인 ETF에 하루 동안 순수하게 들어오거나 나간 돈 |
| 김치 프리미엄(김프) | 국내 거래소 BTC 가격이 해외보다 비싼 비율 [35] |
| 다중 시간대 분석(MTF) | 큰 봉에서 방향을 보고 작은 봉에서 진입 시점을 잡는 방법 |
| 데이터 스누핑 | 같은 데이터로 규칙을 많이 시험하다 보면 우연히 잘 맞는 규칙이 걸리는 함정 |
| 표본 외(Out-of-sample) | 규칙을 만들 때 쓰지 않은 기간의 데이터로 다시 확인하는 것 |
| 샤프 비율 / MDD | 위험 한 단위당 수익(높을수록 좋음) / 고점 대비 최대 손실 폭 |
| 룩어헤드 편향 | 당시에는 알 수 없던 미래 정보가 분석에 섞이는 오류 |
| 보정(Calibration) | "70% 확신"이라고 말한 신호가 실제로 70% 맞도록 숫자를 맞추는 일 |

### 2.3 계열별 상세

#### A. 재량형 가격행동: 지지·저항, 시장구조, 캔들 패턴, 라운드 넘버

| 항목 | 내용 |
|---|---|
| 핵심 아이디어 | 과거에 여러 번 멈춘 가격대와 고저점 순서로 추세와 반전을 판단한다 |
| 필요 데이터 | OHLCV만 있으면 된다 |
| 코드 판정 | 수평 수준(전고·전저, 스윙 고저점, 라운드 넘버)은 ◎. "이 지지가 의미 있는가"는 ✕라서 Claude나 사람이 본다 |
| 근거: 지지·저항 | 외환시장에서 대형 은행의 실제 주문 9,700건을 분석했더니 **익절 주문은 라운드 넘버에, 손절 주문은 라운드 넘버 바로 너머에 몰려 있었다**. 익절 주문은 추세를 되돌리고 손절 주문은 추세를 가속한다. 공개된 지지·저항 수준은 장중 전환점을 예측했다 (Osler, 뉴욕 연준 보고서) [12] (검색 요약) |
| 근거: BTC 라운드 넘버 | BTC 가격이 '00'으로 끝나는 숫자에 몰린다는 가격 군집 연구가 여러 건 있다. 장중 가격에서도 나타난다 [13] (검색 요약). 10만 달러 같은 심리적 장벽을 뚫는 데 과거에 15~30번 시도가 필요했다는 분석도 있다(업계 분석가, 학술 아님) [13] (검색 요약) |
| 근거: 캔들 패턴 | 미국 다우 구성 종목(1992~2002)에서 캔들 패턴 전략은 무작위 매매와 통계적으로 다르지 않았다. 일본 주식 100종목에서도 가치가 없었다 (Marshall·Young·Rose 2006, Marshall·Young·Cahan 2008). 대만·태국 등에서는 일부 상승 반전 패턴이 유효했다는 반대 결과도 있다 [11] (검색 요약). BTC 대상 연구는 이번에 찾지 못했다 |
| 근거: 자동 패턴 인식 | 머리어깨형 같은 모양을 커널 회귀(곡선을 부드럽게 맞추는 통계 기법)로 자동 인식해 1962~1996년 미국 주식에 적용한 결과, 일부 패턴은 **추가 정보를 줬다** (Lo·Mamaysky·Wang 2000) [14] (검색 요약). "모양"을 사람 눈이 아니라 코드로 정의하면 검증할 수 있다는 선례다 |
| 인기 | 글로벌·한국 모두 기본기로 통한다. 국내 입문 글도 "추세 파악, 명확한 지지·저항, 거래량 확인. 보조지표 수십 개 금지"를 권한다 [42] (검색 요약) |
| 권고 | 수평 수준 계산과 라운드 넘버는 **채택**(이미 ST §4에 대부분 있다). 캔들 패턴 **이름**은 확신도 가점에서 **제외**한다. 몸통·꼬리 비율 같은 **수치**는 유지한다 |

| 항목 | 내용 |

| 인기 | 2023~2025년에 가격행동 커뮤니티에서 폭발적으로 퍼졌다 [18] (검색 요약). 업체(LuxAlgo)는 자사 SMC 지표가 TradingView 1위에 올랐다고 밝혔다(업체 주장) [18]. 한국에서도 오더블록·SMC 설명 블로그가 늘고 있다 [42] (검색 요약) |

#### H. 퀀트형 (추세추종, 시계열 모멘텀, 평균회귀, 브레이크아웃)

| 인기 | 글로벌 퀀트 업계 중. 한국 개인 트레이더 사이에서는 하. 단, 변동성 돌파는 국내 자동매매 입문자 사이에서 상 |
| 권고 | ① **4H 방향 필터 후보**에 "일봉 돈치안 채널 앙상블" 또는 "12주 수익률 부호"를 추가해 현행(허리 + MA 배열)과 비교한다 ② 성과를 잴 때 **"단순 추세추종"과 "무작위 진입 + 같은 리스크 규칙"을 비교 기준(벤치마크)**으로 둔다 ③ 시간봉 평균회귀 근거는 "돌파 봉 추격 금지, 되돌림 확인 후 진입"(ST L1·L3)을 뒷받침한다 |

| 권고 | ① Claude에게는 코드가 계산한 **수치 JSON을 주 입력**으로 준다. 차트 이미지는 사람용으로만 쓰거나 A/B 비교로만 넣는다 ② **롱·숏 편향 지표**를 상시 기록한다 ③ Claude가 개입한 신호의 성과는 **과거 백테스트로 평가하지 않는다**. 오늘부터 쌓는 전향적 페이퍼 트레이딩으로만 평가한다 ④ 사람 승인 구조를 유지한다 (PLAN §1) |

#### 2.5.3 두 방식에 공통으로 보완할 점

1. **추세추종 필터가 빠져 있다.** 학술 근거가 가장 강한 느린 추세추종 [2][4]을 4H/일봉 방향 필터 **후보**로 넣어 비교한다.
2. **파생 데이터가 빠져 있다.** BTC 선물에서는 레버리지 쏠림이 급락·급등을 키운다 [28]. 펀딩비·OI는 **과열 필터**로만 쓴다.
3. **정의 공백은 "같은 계열의 표준 정의 여러 개 → 백테스트로 선택"**으로 메운다. 단, 후보를 많이 넣을수록 데이터 스누핑 위험이 커지므로 §3.2-⑧의 절차를 지킨다.
4. **두 사람의 진짜 강점은 리스크 관리와 규율**이다. 이것은 이미 ST §8에 더 보수적으로 반영돼 있다.

| ④ | "Claude 페이퍼 트레이딩: 코드 후보 + Claude 해석 신호를 기록만 하고 사후 집계" (ST §9.3) | 과거 차트로 Claude를 돌리면 모델이 이미 **알고 있는 결과**가 섞인다 | 룩어헤드·기억 편향 연구 [41] | 코드 규칙은 과거 데이터로 백테스트한다. **Claude가 개입한 성과는 오늘부터 앞으로 쌓이는 신호로만** 평가한다(전향적). Opus 5.5의 학습 데이터 기준 시점은 공식 모델 문서에서 **확인 필요**다 |
| ⑤ | MA 7·25·99와 4H 허리로 큰 방향 판정 (ST §3, §4) | 7/25/99는 거래소 기본값일 뿐 근거가 없다 (ST C2) | 느린 신호(12주)가 BTC에서 우세 [2]. 돈치안 앙상블의 성과 [4] | 4H 방향 필터를 다음 3가지로 백테스트해 비교한다. (a) 현행: 허리 + MA 배열 (b) **일봉 돈치안 채널 앙상블**(예: 20·55일 등 여러 기간 평균) (c) **12주 수익률 부호**. 결과가 비슷하면 가장 단순한 것을 고른다 |
| ⑥ | 분석 주기 1시간봉 (PLAN §3.3) | 1~4시간 구간에는 되돌림 잡음이 크다. 알림이 하루 최대 24회라 피로도가 높다 | [2][5][6] | **1H 신호와 4H 신호를 같은 리스크 규칙으로 백테스트해 비교**한다. 근거와 피로도 모두 **4H 신호 + 1H·15m 타이밍**이 유력하다. 결정은 백테스트 뒤에 한다 |
| ⑦ | 손익비 ≥ 1.5 | 문제는 아니다. 다만 뜻을 명시해야 한다. 손익비 1.5에서 본전 승률은 1 ÷ (1 + 1.5) = **40%**이고, 수수료와 슬리피지를 넣으면 더 높아진다 | 계산 | 백테스트 합격 기준을 "수수료 포함 승률 > 본전 승률 + 여유"로 적어 둔다 |
| ⑧ | 파라미터 비교 계획 (ST §9: 허리 2종 × 기준가 2종 × 배수 2종 × 손익비 2종) | 이 문서의 제안까지 더하면 기준가 3종, 방향 필터 3종으로 **조합이 수십 개**가 된다. 그러면 우연히 좋은 조합이 뽑힌다(데이터 스누핑) | 표본 내에서는 유의했던 규칙이 BTC 표본 외에서 무너졌다는 결과 [8][9]. 스누핑 보정의 필요성 [7] | ① 후보 목록을 **백테스트 전에 문서로 고정**한다 ② 기간을 나눠 앞 70%로 고르고 뒤 30%로 **한 번만** 확인한다 ③ 워크포워드(기간을 밀어 가며 반복 검증) ④ **"무작위 진입 + 같은 손절·익절·사이징"** 벤치마크를 이겨야 채택한다 |
| ⑨ | 손절 폭 최대 2% (가격 기준) | 2%는 **상한**으로 적절하다. 다만 1H 변동성이 큰 날에는 구조적 손절 자리가 2%를 넘는다. 이때 손절을 억지로 좁히면 휩쏘(흔들고 돌아오는 움직임)에 걸린다 | 손절이 너무 타이트하면 휩쏘에 걸린다는 경험담 (CP §3.13) | "손절 자리가 2%를 넘으면 **손절을 좁히지 말고 진입을 포기**한다"를 규칙으로 명시한다. 포지션 크기는 "계좌 × 1회 위험% ÷ 손절 거리"로 계산하고, 증거금 20%와 레버리지 3배를 상한으로 둔다(ST §8의 1.2% 계산과 같은 원리). 변동성 기반 사이징은 가장 근거가 강한 추세추종 연구가 쓰는 방식이다 [4] |

### 3.5 사용자 결정이 필요한 질문

1. **신호 주기**: 1H와 4H를 백테스트로 비교한 뒤 정하는 데 동의하는가? (근거는 4H 쪽으로 기운다)
2. **확신도 문턱**: 초기에는 Claude 확신도 대신 **코드 점수**로 거르고, Claude 확신도는 보정표가 나올 때까지 기록만 하는 데 동의하는가?
3. **차트 이미지**: 이미지는 텔레그램에서 사람이 보는 용도로만 쓰고, Claude에게는 A/B로만 넣는 데 동의하는가?
4. **유료 데이터**: 코인글래스(월 29달러부터) 같은 유료 데이터는 초기에 쓰지 않고, 바이낸스 무료 데이터와 자체 로그로 시작하는 데 동의하는가?
5. **방향 필터 후보 추가**: 4H 방향 판정에 추세추종 후보(돈치안, 12주 모멘텀)를 넣어 비교하는 데 동의하는가?
