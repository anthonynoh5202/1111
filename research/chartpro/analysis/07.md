- 자막은 유튜브 자동 생성본이라 오타가 많다. 문맥으로 바로잡은 말에는 [추정]을 붙였다. 뜻을 알 수 없는 말은 [판독 불가]로 적었다.
- 자주 나오는 오타 (이 묶음 공통)
  - "춤의/춤/추면" = 추매(추가 매수·추가 진입) [추정]. 손실 중 추매가 물타기, 수익 중 추매가 불타기다 (강사 정의, #11 [08:00]).

  - "맞이/바디/마 디" = 마디 [추정]. "닭 약/다 개학/박 약" = 다계약 [추정]. "틀에/트레" = 트랩 [추정]. "계자/개 자/게 자" = 계좌.

  - "5일/오일" = 원유(오일) 선물, "아스타/나스 탁" = 나스닥 선물 [추정].
- 타임스탬프 [mm:ss]는 해당 발언이 들어 있는 약 20초 구간의 시작 시각이다.
- **읽기 주의**: 이 묶음은 차트 기법보다 **마음가짐·멘토 선택·원칙 세우기·자금·계약 수·매매 스타일**을 다룬다. 차트 규칙은 #6, #7, #8, #9, #12, #13, #14에 조금씩 있고, **숫자 규칙은 #8(틱), #10(시간), #11(자금·계약), #12(다계약), #14(스타일)에 몰려 있다.**

### 【#2】 "내가 고수인가요? 하수인가요?" (나의 현재 상태를 진단하자!) (https://youtu.be/ZNFM9lC0y2E)

- 핵심
  1. 고수까지 4단계(왕초보 → 초급 → 중급 → 상급)가 있다. 내 단계를 알아야 인내·희망·겸손이 가능하다 [01:11~01:37]

  4. 이유 있는(근거 있는) 매매를 해야 손실을 봐도 찾아올 수 있다. 모르고 낸 손실은 찾아올 수 없다 [09:42~10:13][11:37~11:47]
- 규칙
  - [초급 단계] → 본전 생각 금지(조급해지면 감정 매매) [07:53~08:04]

- 용어

  - 확인 매매 = 방향을 확인하고 들어가는 매매 (#13에서 자세히) [09:10]
  - 근거 있는 매매 = 왜 들어갔는지 알고 하는 매매 [09:44~10:13]
- 예시: 계좌 그래프(시간-수익) 그림만.
- 봇 적용: × — 단계 진단. 단 "기준가(지정가 선주문) 매매는 초급에게 위험, 확인 매매 우선"은 봇의 기본 진입 방식을 '확인 후 진입'으로 둘 근거가 된다.

## 묶음 요약

### 반복 등장한 원칙 TOP 5

1. **손절(대응)이 수익보다 먼저다.** 틀리면 인정하고 컷, 필요하면 스위칭. 물타기로 버티는 게 깡통의 원인이다 — #1, #2-1, #4, #5, #6, #9, #10, #11, #12
2. **진입 전에 시나리오를 고정한다.** 진입·손절·익절·예외 조건(횡보 시 탈출, 거래 폭발 시 익절 연장)을 미리 적고, 진입 후 수정하지 않는다. 손절 자리가 확실한 곳에서만 들어간다 — #7, #9, #12, #2(근거 있는 매매)
3. **고정 숫자보다 차트 구조로 정한다.** 하루 손익 한도·고정 틱 손익·일일 횟수 제한은 나쁜 원칙이고, 손절·익절은 마디·기준가·트랩 같은 구조로 정한다 — #8, #9, #12
4. **한 가지 방식만 정한다.** 추세 vs 박스 중 하나, 스캘핑/마디/당일 추세/스윙 중 하나. 초보는 추세 매매 + 마디 매매 + 1계약부터 — #6, #11, #13, #14
5. **박스장에서는 쉬고 추세장에서 한다.** 추세 매매자가 연속 컷을 당하면 박스일 확률이 높으니 추세가 확인될 때까지 관망한다 — #1, #8, #9, #13

(그 밖에 모든 영상에 반복: 겸손·교만 경계, 본전 심리 버리기, 매매일지로 내 원칙 만들기, 혼자 하지 말기.)

### 다른 강의와 연결되는 개념

- **허리(허리라인)**: #6에서 1차 익절 포인트로 쓰였다. 계산 방식은 이 묶음에 없음 → 허리를 정의한 다른 강의와 연결.
- **마디 / 마디 매매 / 매도 마디**: #6, #8, #14. "마디 매매의 기준"으로 컷·익절 범위를 잡는다고만 했다. 마디를 긋는 규칙은 다른 강의에서 가져와야 한다.
- **기준가 / 기준가 매매 / 눌림목 매매**: #2에서 "미리 걸어 두는 매매(초급이 많이 하는 위험한 매매)", #6에서 "눌림목 매매 = 기준가 매매", #12에서 "1차 목표 = 바로 위 기준가". 기준가 정의는 다른 강의와 맞춰 봐야 한다.
