### 【초급-차트편#1】 캔들 기초강의 ① — 캔들의 원리, 상위·하위 캔들 (https://youtu.be/0KC9TBc3jXc)
- 핵심:
  1. 캔들은 "정해진 기간 동안 가격 움직임"을 시가·종가·고가·저가 네 값으로 그린 것이다 [01:42]
  2. 같은 캔들 하나도 그 안의 움직임은 여러 가지일 수 있다 (고가를 먼저 찍었는지 저가를 먼저 찍었는지) [03:36][09:45]
  3. 상위 캔들과 하위 캔들은 서로 바꿔 볼 수 있다. 주봉 1개 = 일봉 5개, 일봉 1개 = 30분봉 13개(주식 6시간 반 기준) [08:19][09:09]
  4. 오늘의 포인트는 "하나의 캔들을 여러 패턴으로 그려낼 수 있다"와 "상위·하위 캔들 관계를 유연하게 생각하는 것" [09:45][10:03]
- 규칙: (이 편은 개념 설명만 있고 매매 규칙은 없음)
- 용어:
  - 양봉 = 시가보다 종가가 높은 캔들, 빨간색 [02:57]
  - 음봉 = 시가보다 종가가 낮은 캔들, 파란색 [04:15]
  - 십자형(도지) 캔들 = 시가와 종가가 같아 몸통이 없는 캔들 [05:36]
  - T자형 캔들 = 몸통·윗꼬리 없이 아래꼬리만 긴 캔들. 고가=시가=종가 [06:20]
  - 상위 캔들 / 하위 캔들 = 일봉의 상위는 주봉, 하위는 30분봉 등 [08:19][09:27]
- 예시: 주식 9시~15시 30분 장, 일봉·주봉·30분봉 그림 설명
- 봇 적용: ◎ — 여러 봉을 합친 OHLC(리샘플링)는 바로 코드화 가능. 이후 #3·#4 "합치고 쪼개기"의 기초

### 【초급-차트편#2】 캔들 기초강의 ②-1 — 시가·몸통·갭 (https://youtu.be/OcOIgohHGLY)
- 핵심:
  1. 주식에는 동시호가(장 시작 전·마감 전 주문을 모아 한 번에 체결)가 있어 시가가 전일 종가와 다를 수 있다. **코인·해외선물에는 없다** [00:39][00:59]
  2. 시가는 종가처럼 "합의된 가격"이라 기본적으로 지지·저항 역할을 한다 [03:32]
  3. 몸통(시가~종가)은 그날 힘의 크기를 보여준다. 다만 캔들 하나만 보지 말고 추세 시작점부터 묶어서 봐야 한다 [04:51][06:39]
  4. 중요한 위치에서 갭상승 + 장대양봉 + 거래량이 함께 나오면 우상향 확률이 높다 [04:30]
- 규칙:
  - [큰 악재 + 갭하락으로 시가 형성] → 하락 추세 가능성 높음 (항상은 아님) [03:51]
  - [중요한 위치 + 갭상승 + 장대양봉 + 거래량 터짐] → 우상향 확률 높음 [04:30]
  - [하락 추세 중이라도 대량거래 + 장대양봉] → 그 캔들 하나만으로도 의미 있음. 그 외에는 추세 시작점부터 묶어서 판단 [07:03]
- 용어:
  - 갭상승 / 갭하락 = 전일 종가보다 위 / 아래에서 시가가 형성되는 것 [02:56]
  - 몸통 = 시가와 종가의 차이(네모 박스). 당일 매수세가 점령한 범위, 당일 힘의 크기 [04:51]
- 예시: 주식 일봉, 30분봉 3일치를 일봉 3개로 합쳐 그리기 [07:22]
- 봇 적용: ○ — 몸통 크기는 ◎. 갭·동시호가는 24시간 거래인 BTC 무기한 선물에는 해당 없음(강사도 코인엔 없다고 함)

### 【초급-차트편#2】 캔들 기초강의 ② — 종가·고가·저가의 진짜 의미 (https://youtu.be/aaUtmHMHfbQ)
- 핵심:
  1. 차트는 항상 매수 세력과 매도 세력의 싸움으로 봐야 한다 [00:17]
  2. 시가·종가·고가·저가 중 **종가가 가장 중요**하다. 마지막으로 합의된 가격이라 지지·저항 역할을 한다 [00:38][02:20]
  3. 시·종·고·저의 의미는 **중요한 캔들(거래 터지고 중요한 기준가를 돌파한 장대양봉)**에서만 크다 [02:41][03:00]
  4. 고가·저가는 "밀린 것인지, 밀리는 척(허용)한 것인지" 둘 중 하나다. 하위 캔들이나 다음 날 반응으로 가린다 [06:16][06:57]
  5. 변동폭(고가-저가)이 평소보다 갑자기 커지면 곧 시세가 난다 [10:18]
- 규칙:
  - [양봉 마감] → 다음 날 오를 확률 높음. 밀려도 전일 종가에서 지지받을 확률 높음 [01:09]
  - [음봉 마감] → 다음 날 내릴 확률 높음. 반등해도 전일 종가에서 저항받을 확률 높음 [01:42]
  - [종가 = 고가인 양봉] → 매수 세력 일방 승리, 다음 날 오를 확률 높음 [03:38]
  - [중요 장대양봉의 종가] → 이후 여러 날 지지선 (예시: 4일 연속 지지) [03:21]
  - [평소 1~5% 움직이던 종목이 10~15% 변동] → 곧 위나 아래로 시세 날 확률 높음. 평소 10~15% 움직이는 종목은 최소 25~30%는 움직여야 시세 기대 [10:18][11:35]
  - [작은 캔들이 이어지다 긴 캔들 출현] → 그 방향으로 시세 이어질 수 있음 (긴 음봉이면 하락 전환) [10:57][12:17]
- 용어:
  - 종가 = 매수자와 매도자가 마지막으로 합의한 가격, 둘 사이 혈투의 최종 스코어 [00:54]
  - 양봉의 고가 = 매수자가 끌어올린 최대 가격이자 매도자가 마지막으로 저항하기 시작한 가격 [04:21]
  - 양봉의 저가 = 매수자가 허용할 수 있는 최저 가격(매수자에게 중요한 가격대) [04:42][05:40]
  - 음봉의 고가 = 매도자가 허용할 수 있는 최고 가격(매도자에게 중요한 가격대) [08:58][09:16]
  - 변동폭 = 고가와 저가의 차이. 매수·매도 세력의 강약을 보여주고 앞으로의 시세를 예고 [10:00]
- 예시: 주식 일봉 장대양봉, T자형 캔들 이후 급등
- 봇 적용: ○ — "종가=지지·저항", "변동폭 ÷ 평소 변동폭(예: ATR 배수)"은 ◎. "밀린 것인지 밀리는 척인지"는 하위봉·다음 봉 반응으로 근사만 가능

### 【초급-차트편#3】 캔들의 힘 싸움 — 힘의 균형과 세기 (https://youtu.be/nNbEXzQC3fo)
- 핵심:
  1. 누가 이겼는지뿐 아니라 **얼마나** 이겼는지를 판단해야 한다 [00:00]
  2. 캔들 크기가 클수록 강하다. 같은 10% 상승이라도 밀렸다가 끌어올린 T자형이 그냥 오른 장대양봉보다 더 강하다(다운됐다 일어나 KO시킨 복서) [01:05][02:23]
  3. **양봉이라도 종가가 (고가+저가)의 중간 아래면 매도 승리**. 색이 아니라 종가의 위치로 판단 [04:00]
  4. 종가가 정확히 중간이면 하위 캔들로 어떤 순서로 움직였는지 봐야 한다 [05:40][07:18]
  5. 캔들 하나가 아니라 캔들 군(2개, 3개, 5개…)을 합쳐서 봐야 한다 [10:05][11:48]
- 규칙:
  - [종가 > (고가+저가)/2] → 매수 우위 / [종가 < (고가+저가)/2] → 매도 우위 [04:00][08:55]
  - [고점에서 역망치형(위로 올랐다 밀린) 캔들] → 밀리는 예가 많음 (무조건은 아님) [04:35]
  - [종가가 딱 중간] → 하위 봉에서 "급등 후 살짝 눌림"이면 매수 승, "급락 후 반등"이면 매도 승 [06:10]
- 용어:
  - 역망치 캔들 = 망치를 뒤집어 놓은 모양(윗꼬리가 긴 캔들) [07:51]
  - 캔들 군 = 여러 캔들을 묶어서 하나로 보는 것 [10:05]
- 예시: 주식 일봉. 장대양봉 다음 날 갭상승 음봉을 두 개 합치면 +3% 매수 승 [10:05]
- 봇 적용: ◎ — 종가 위치 = (종가−저가)/(고가−저가), 0.5 기준. 봉 N개 합친 뒤 같은 계산. 강사가 직접 "중간을 갈라 보라"고 정의함
- 기타: 강사는 "캔들과 거래량 두 가지만 보고 매매한다, 둘 중 하나를 고르라면 캔들" [12:22]

### 【초급-차트편#4】 캔들 쪼개고 합치기 — 차트 힘의 분석 (https://youtu.be/-vFKpVjo7vE)
- 핵심:
  1. 캔들을 합치고 쪼개는 목적은 "힘의 균형(누가 이겼나)"을 판단하기 위해서다 [05:50]
  2. 월요일 장대음봉 + 화요일 장대양봉 = 합치면 T자형 → 수요일은 매수 관점 [02:48][04:09]
  3. 오래 팽팽하게 횡보(줄다리기)하면 어느 한쪽 힘이 빠질 때 한 번에 쏠린다. 그 라인을 돌파·이탈하면 시세가 세게 나온다 [09:37][10:09]
  4. 몇 개를 합쳐 볼지는 매매 스타일(단타·장기)에 따라 다르다 [11:40]
- 규칙:
  - [직전 봉(또는 봉 묶음)이 매수 승] → 다음 봉은 매수 관점 / [매도 승] → 매도 관점 [03:30][07:40][13:01]
  - [긴 횡보 박스(합치면 도지)] → 위든 아래든 박스 라인 돌파·이탈 시 시세가 세게 나옴 [10:09]
- 용어:
  - 캔들 쪼개기·합치기 = 여러 봉을 한 봉 OHLC로 합치거나 한 봉을 하위 봉으로 펼치는 작업 [00:00]
- 예시: 주식 일봉 3일 합치기, 몇 달 횡보 후 장대양봉 급등
- 봇 적용: ◎ — N봉 합성 OHLC + 종가 위치(0.5 기준). 박스 돌파는 ◎(박스 정의 필요)

### 【초급-차트편#5】 거래량의 비밀 ① (https://youtu.be/0tgkq8_dI4M)
- 핵심:
  1. 거래량은 **신뢰도**다. "주가는 속여도 거래량은 못 속인다" [01:48][16:59]
  2. 거래량이 많으면 주가가 **움직인다**(오를 수도 내릴 수도) [02:30]
  3. 조정(눌림) 때는 거래량이 줄어드는 게 정상이다 [08:42]
  4. 거래량(매물대)은 지지·저항 역할을 한다 [11:21]
  5. 거래량 증가에는 반드시 이유가 있다 [17:20]
- 규칙:
  - [종목 선정] → 거래량 많은(참여도 높은) 것 위주 [01:08]
  - [장대양봉 + 거래량 급증] → 믿을 수 있는 상승(매수 세력이 능동적으로 이김) / [장대양봉인데 거래량 없음] → 매도 세력이 약해서 오른 것, 곧 다시 내려올 가능성 높음 [05:49][06:32]
  - [상승 후 조정 중 거래량 감소] → 건강한 조정, 2차 상승 기대, 매수 준비 [09:41][16:39]
  - [상승 후 하락하는데 거래량 터짐] → 이상 신호. 박스로 가거나 급락 가능, 주의 [10:03][16:39]

### docs/STRATEGY.md §11.1 질문에 대한 이 묶음의 답 (자막 근거)
- **Q1 기준봉 조건**: 거래량 배수는 **강사가 숫자를 주지 않았다**("확연히 증가", "차트는 계산이 아니라 감각" #11 [02:50][03:08]). 몸통은 "장대봉". 양봉만이 아니라 하락이면 장대음봉도 됨 [02:14]. 추가로 이평선 우상향, 종가 기준 전고 돌파, 이격 벌어짐·직전 고점 저항 시 제외.
- **Q2 기준마디·허리**: 기준마디는 **여러 봉 구간**(기준봉 전 상승 시작점~조정 직전) #12 [02:47][03:05]. 허리는 "중간 부분의 지지 세력가, **무조건 중간값은 아님**" [04:05] — 고저 중간인지 몸통 중간인지는 이 묶음에 없음(후속 허리 강의 필요).
- **Q3 세력가/기준가 가격**: 거래 터진 캔들을 **분봉**으로 펼쳐 **가장 많이 횡보·지지·저항 받은 가격**, 라운드 피겨는 기본 기준가 #8 [03:54][07:21][08:39]. 최다 거래량 봉의 시가·종가나 VWAP라는 말은 없음.
- **Q6 눌림목 판정**: 되돌림 % 수치는 없음. 조건은 기준봉·마디 이후, 거래 감소, 허리 위 기준가 지지(최대 허리) #17 [03:55].
- **Q7 이평선 기간**: 5·20·60·120·240, 매수 급소는 A3 #13·#14·#15.
