## 3. 기법별 정리

표기: 【근거】 인용문은 댓글 원문입니다(작성자 표시가 없으면 시청자 댓글). 조건·진입·손절·익절 항목에서 "확인 필요"는 자료가 없다는 뜻입니다.

### 3.1 기준봉
- **정의**: 지지·저항 매매의 기준이 되는 봉. 거래량이 신뢰도를 보여 준다.
  【근거】 "지지와 저항 매매 기주 기준봉을 찾는 것이 제일 중요하다 … 거래량은 신뢰도이다" — [초급-차트편#11 기준봉](https://youtu.be/A4fhqVhlV1Q)
- **조건**: 거래량이 크게 실린 봉이라는 점은 여러 곳에서 암시됩니다(3.3, 3.4). 몇 배 이상이어야 하는지, 봉의 크기는 어느 정도인지는 **확인 필요**
- **진입**: 2차 기준봉이 나오면 매수 (3.2 기준마디 요약)
- **손절 / 익절**: 확인 필요
- **신뢰도**: 하~중

### 3.2 기준마디 → 허리 → 지지 확인 → 진입
- **정의**: 기준마디는 기준이 되는 가격 구간입니다. 허리는 그 구간의 중심값이자, 지지와 저항이 바뀌는(추세가 전환되는) 자리입니다.
- **조건 / 진입 / 손절** (좋아요 29개 요약 댓글):
  > "<매매 포인트> 1. 기준마디를 찾아라 2. 허리(중심값)을 찾아라 3. 지지 하는지를 확인하라 4. 2차 기준봉 출현, 저항 라인 돌파, 기타 패턴 나오면 매수 5. 손절은 지지라인 이탈 시" — [초급-차트편#12 기준마디](https://youtu.be/dTGsswbakyU)
- **허리 판정**: "기준봉 찾고 [추세전환되면] … 지지 받고 저항받는 자리 추세전환되는 자리가 허리 지점. 거기에서 밑이면 매도 위에면 매수" (좋아요 14) — [초급-차트편#23 허리](https://youtu.be/Yyb85UrGF4c)
- **익절**: 확인 필요
- **신뢰도**: **중**. 두 영상의 요약 댓글이 서로 맞고, 구조화되어 있습니다. 봇에 넣기 가장 좋은 후보입니다.
- 관련 시청자 증언: "기준마디를 찾아서 어디서 대응하고 눌림과 돌파를 이해하고 원웨이 패턴으로 끝까지…" — [중급-차트편#2](https://youtu.be/un0gzkLM5e4)

### 3.3 세력가 / 기준가 (기준선)
- **정의**: 거래량이 터진 봉 안에서 세력이 매집한 가격대. 이 가격이 이후 지지·저항 기준선이 됩니다. 해시태그: #세력가찾는법 #기준선설정 #기준가매매 #지지와저항 #세력선매매 ([#33](https://youtu.be/PCPGNjF4nko), [#34](https://youtu.be/l-4fZQ7fgIU), [중급#15](https://youtu.be/B-8-CXFhLK4))
- **조건 / 진입 / 익절** (시청자 요약):
  > "(1)매수분석: 일봉차트(거래량이 터진 일봉 주목) → 5분봉 차트(그 일봉을 5분봉으로 쪼개 그 일자의 지지대를 파악하여 그 가격에서 매수) (2)매도분석: 60분봉 차트(1달 전 거래량이 터진 구간 주목) → 5분봉 차트(그 구간을 5분봉으로 쪼개 1달 전의 저항구간 파악. 그 가격에 도달 시 매도)"
  > "12:08 거래량이 터진날의 분봉을 보면 기준가를 추정할 수 있다." — [초급-차트편#8 세력가 찾는 방법](https://youtu.be/4BmrTkiCzvE)
- "절대 기준가"와 "일반 기준가"라는 두 종류가 있다는 댓글이 있습니다 — [중급-차트편#10](https://youtu.be/4coUOxzrf6o). 추가 매수는 매수마다 따로 보고, 평단가를 절대 기준가로 삼지 말라는 해석도 있습니다 — [중급-차트편#22](https://youtu.be/N_JTpzqvYfE)
- **손절**: 기준가(지지)를 이탈하면 손절(3.2와 같은 원리로 추정). **확인 필요**
- **신뢰도**: 중 (상위 봉에서 거래량 급증 봉을 찾고 하위 봉에서 가격대를 뽑는 구조는 분명함). 분봉 안에서 "지지대"를 무엇으로 정하는지(최다 거래량 가격? 몸통 하단? 시가?)는 **확인 필요**

### 3.4 거래량
- **요약** (좋아요 99개 댓글, [초급-차트편#5 거래량의 비밀](https://youtu.be/0tgkq8_dI4M)):
  1. 거래량이 많으면 가격이 크게 움직인다.
  2. 고점을 찍고 조정할 때는 거래량이 줄어드는 것이 정상이다. 이런 건강한 조정 뒤에는 2차 상승을 기대할 수 있다. 조정 중 거래량이 터지면 급락이 이어지거나 변동성이 커진다.
  3. 거래량이 터진 곳은 지지·저항 역할을 한다.
  4. 가격은 속여도 거래량은 속이지 못한다.
  5. (매수 조건) 매물대에서 지지가 예상되는 시점 + 최근 2~3개 캔들에서 전환(반전) 분위기 + 거래량
- 차트 강도 3요소는 **거래량, 속도, 심리(파동)**입니다. 거래량이 늘어난 곳은 매물대가 됩니다 — [초급-차트편#6](https://youtu.be/m0IQAZm0Uvg) 댓글
- "거래량 터진 곳에서 매매하라"(좋아요 446개 댓글이 강의 문구로 인용) — [초급-차트편#38](https://youtu.be/cr1Imugb2gg)
- **신뢰도**: 중 (요약이 구조화되어 있고 여러 영상에서 반복됨)

## 4. 시그널 봇 규칙 후보

코드화: ◎ 바로 가능 / ○ 파라미터를 확인한 뒤 가능 / △ 정의부터 확인 필요 / ✕ 코드화 불가(운용 원칙)
**숫자는 모두 제안값이며 차트프로가 제시한 값이 아닙니다.**

| # | 규칙 (조건 → 행동) | 근거 | 코드화 |
|---|---|---|---|
| R1 | **기준봉 검출**: 상위 봉(예: 1H/4H)에서 거래량이 직전 N봉 평균의 k배 이상인 봉 → 기준봉으로 등록 (제안 N=20, k=3) | 3.1, 3.3, 3.4 | ○ |
| R2 | **기준가 산출**: 기준봉 구간을 하위 봉(예: 5m)으로 쪼개 가격대를 뽑는다. 거래량 가중 중심가(구간 VWAP) 또는 최다 거래 가격을 기준가로 쓴다 | 3.3 ("그 일봉을 5분봉으로 쪼개 지지대 파악") | ○ (어떤 가격을 쓰는지 확인 필요) |
| R3 | **허리 필터**: 기준마디(기준봉 고가~저가)의 중심값 = (고+저)/2. 종가 > 허리이면 롱만, 종가 < 허리이면 숏만 허용 | 3.2 ("밑이면 매도 위에면 매수") | ◎ (허리를 몸통 기준으로 잡는지 확인 필요) |
| R4 | **기준가 지지 확인 롱**: 가격이 기준가·허리까지 되돌림 → 지지 확인(하위 봉 종가가 기준가 위에서 마감, 반전 캔들 1~2개) → 2차 기준봉(거래량 증가 양봉) 또는 직전 저항 돌파 시 진입 | 3.2 매매 포인트 1~4, 3.4 요약 5 | ○ |
| R5 | **손절 = 지지 이탈**: 롱은 기준가(또는 기준마디 저점) 아래 종가 이탈 시 청산. 진입과 동시에 손절 주문을 건다 | 3.2 매매 포인트 5, 3.13 | ◎ |
| R6 | **손익비 필터**: (목표가 − 진입가) / (진입가 − 손절가) ≥ R (제안 R=2)가 아니면 진입하지 않음 | 3.13 "원하는 이익만큼 따져서 손절" | ◎ |
| R7 | **목표가 = 과거 거래량 급증 구간(저항)**: 상위 봉에서 과거 거래량이 급증한 구간 중 가장 가까운 위쪽 가격대를 1차 목표로 설정 | 3.3 매도분석, 3.14 | ○ |
| R8 | **건강한 조정 판정**: 고점 이후 되돌림 구간의 평균 거래량이 직전 상승 구간보다 작으면 눌림 롱 후보 유지. 되돌림 중 거래량이 급증하면 후보 폐기 | 3.4 요약 2 | ◎ |
| R9 | **돌파 거래량 확인**: 전고점 돌파 봉의 거래량이 평균 이상일 때만 돌파 진입. 돌파 직전 거래량이 감소하면 보류 | 3.4, 3.8, 3.14-4 | ○ |
| R10 | **연속 양봉 돌파 시 역방향 금지**: 5m에서 전고점을 음봉 없이 양봉 3개 이상, 거래량 동반으로 넘으면 숏 신호 차단, 다음 눌림에서 롱 대기 | 3.7 트랩 예시 | ○ (트랩·짝궁뎅이 정의 확인 필요) |
| R11 | **눌림 실패 손절**: 눌림 롱 진입 뒤 M봉 안에 직전 고점을 돌파하지 못하고 기준가를 이탈하면 청산 | 3.7 | ○ |
| R12 | **이평선 전환 예고**: N기간 SMA에서 다음 봉에 빠질 종가(close[t−N+1])가 현재가보다 낮고 거래량이 증가하면 → "이평 상승 전환 임박" 가점 | 3.6 | ◎ (어떤 기간을 쓰는지 확인 필요) |
| R13 | **멀티 타임프레임**: 상위 봉에서 방향과 구간(기준가·허리)을 정하고, 하위 봉 돌파·지지로 타점을 잡는다. 상위와 하위 방향이 반대면 진입하지 않음 | 3.3, 3.8 | ◎ |
| R14 | **이벤트 필터**: CPI·FOMC 등 주요 지표 발표 전후 T분 동안 신규 진입 금지 | 3.14-5 | ◎ (경제 캘린더 데이터 필요) |
| R15 | **분할 진입 독립 관리**: 추가 진입은 각각 손절을 따로 두고, 평단가로 손절을 옮기지 않는다. 역행하면 최근 진입분부터 청산 | 3.13 | ◎ |
| R16 | **역추세 예측 진입 금지**: R3 허리 필터와 상위 봉 추세에 반하는 신호는 버린다 | 3.16 | ◎ |
