# 캔들 학습 실험

과거 바이낸스 BTCUSDT 1시간봉(2020-01 ~ 2026-09)으로 "캔들에서 무엇을 배울 수 있나"를 잰다.
학습은 프로그램(머신러닝)이 하고, Claude는 학습 결과를 읽고 설명한다(Claude 모델 자체를 데이터로 학습시키지는 않는다).

- `learn_v0.py` — 특징 51개(캔들 모양 1h·4h·24h, 거래량, 테이커 매수 비율, 변동성, 이평 거리, 고점·저점 거리, 시간),
  LightGBM·로지스틱 회귀, 2020~2022 학습 · 2023 조기 종료용 · 2024-01~2026-09 검증(72시간 엠바고), 연도별 워크포워드.
- `learn_v0_result.json` — 결과.

v0 결과 요약(검증 구간):
- 방향(24시간 뒤 상승?): AUC 0.529(동전 0.5), 연도별 0.52~0.55. 매일 1회 매매로 바꾸면 비용 뒤 거의 0 → 돈이 되지 않음.
- 크기(24시간 고가~저가 폭): R² 0.33, 상관 0.60(직전 24시간 폭을 그대로 쓰면 R² −0.27) → 변동성은 잘 배운다.
- 목표 먼저(+2%가 −1%보다 먼저, 72시간): AUC 0.516, 모델 상위 9%도 기대값 약 0R → 우위 없음.
- 중요한 특징은 캔들 한 개의 모양보다 맥락(장기 이평 거리, 테이커 매수 비율, 주간 변동성, 고점·저점 거리)이었다.

실행(라이브러리는 저장소 설치 목록 밖이라 별도 가상환경):
```
python3 -m venv ~/mlenv && ~/mlenv/bin/pip install numpy pandas scikit-learn lightgbm
~/mlenv/bin/python research/learn/learn_v0.py ~/learn_out
```
