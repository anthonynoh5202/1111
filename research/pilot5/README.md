# 5만 원 테스트 (2026-11-12)

"캔들 분석으로 돈을 벌 수 있는지 5만 원으로 시험해 보자"에 대한 설계와 도구.

| 파일 | 내용 |
|---|---|
| `PROTOCOL.md` | 규칙서. 무엇을 재는지, 매일 할 일, 멈춤 규칙, 12주 뒤 판정 |
| `pilot.py` | 도구. 신호 확인(`now`), 모의 성적(`paper`), 내 기록 채점(`score`). 공개 시세만 읽고 주문 기능이 없다. 파이썬 기본 기능만 쓴다 |
| `journal_template.csv` | 일지 양식. `journal.csv`로 복사해서 쓴다 |
| `pilot_analysis.py` | 설계에 쓴 과거 자료 계산. 결과는 `results/analysis.json`, `results/execution_sim.csv` |
| `test_pilot.py` | 도구가 연구 코드와 같은 값을 내는지 확인 |

## 맥에서 쓰는 법
```
cd research/pilot5
python3 pilot.py paper     # 2026-09-29 이후 처음 보는 자료에서 신호가 어땠는지(돈 없이)
python3 pilot.py now       # 밤 9시 직후: 오늘 신호와 주문표
cp journal_template.csv journal.csv
python3 pilot.py score journal.csv
```

## 핵심 결과
- 신호의 힘은 롱 쪽에만 있었다. 롱 신호 뒤 16시간 수익이 '아무 때나 롱'보다 2020~2023년 +0.147%p(t 2.24), 2024~2026년 +0.180%p(t 2.96) 높았다. 숏 쪽은 두 기간 모두 손해였다.
- 실제 비용은 거래당 약 0.073%로 추정된다(지정가 체결률 95%, 실행 손해 0.057%p, 펀딩 0.016%).
- 5만 원으로는 최소 주문(0.001 BTC ≈ 75 USDT)이 계좌의 2.1배다. 12주 약 12번 거래의 손익은 실력이 없어도 46%, 있어도 55% 확률로 플러스다. 손익으로는 아무것도 가릴 수 없다.
- 12번으로 잴 수 있는 것은 규율과 비용이다. 신호가 진짜인지는 하루 6번 전체를 모의로 약 1.3년 기록해야 가릴 수 있다.

## 확인하지 못한 것
- 이 작업 환경에서는 바이낸스에 접속할 수 없어 `pilot.py`의 실제 시세 읽기는 시험하지 못했다. 과거 자료 파일(`--file`)로만 시험했다.
- BTCUSDT 최소 주문(0.001 BTC, 최소 금액 50 USDT)과 수수료는 뉴스·스냅샷 기준이다. 주문 화면에서 확인해야 한다.
- 국내 거래소의 바이낸스 출금 수수료와 현재 가능 여부.
- 롱만 실전에 쓰기로 한 것은 결과를 본 뒤의 결정이다. 2026-09-29 이후 자료에서 다시 확인한다.
