## 0. 이 문서를 읽는 법

- 시간이 없으면 **§1(결론 요약)**과 **§5(사용자 결정 목록)**만 읽는다.
- 지적 ID의 접두어: **Q** = 품질·검증 방법 · **SEC** = 보안 · **F** = 제품·실행 가능성 · **A** = 대안 제안. `Q1+F01`처럼 묶인 ID는 서로 다른 검토자가 같은 문제를 따로 지적해서 하나로 합친 것이다.
- 심각도 뜻
  - **critical**: 지금 고치지 않으면 되돌릴 수 없는 피해가 나거나, 앞선 작업 전체가 버려질 수 있다
  - **high**: 실거래 전에 반드시 고쳐야 한다
  - **medium**: 설계에 넣으면 더 안전하거나 판단이 정확해진다
  - **low**: 사용성·보조 개선
- 판정 규모: 채택 35건(critical 2 · high 13 · medium 15 · low 5), 기각 5건(일부 기각·연기 포함), 대안 15건 판정, 결정값 22개(D1~D22), 사용자 결정 10개.

## 1. 결론 요약

### 1.1 한 문단 결론

**큰 방향은 맞다.** 사람이 승인해야 주문이 나가는 반자동 구조, 텔레그램 폴링, 바이낸스 선물, 출금 금지 키, 손절 필수·격리 마진·레버리지 3배는 조사 결과와 맞는다. **틀린 곳은 네 가지다.**

1. **순서**: 규칙이 돈을 버는지 확인(백테스트)하기 전에 Claude·텔레그램·주문 연동부터 만든다 (Q1+F01).
2. **Claude의 역할**: 차트 방향을 맞히는 능력이 확인되지 않은 Claude에게 방향과 진입·손절·익절 가격 판단을 맡겼다 (Q3+F02).
3. **검증 기준**: "테스트넷 1~2주 운영"과 "확신도 0.6"으로는 전략의 좋고 나쁨을 가릴 수 없다 (Q4+F10, Q11).
4. **보안 전제**: GitHub 저장소가 지금 공개 상태인데 비공개를 전제로 설계했다. 서버가 뚫렸을 때의 피해 상한도 정해져 있지 않다 (SEC-01, SEC-02).

### 4.1 Claude의 역할: LLM이 직접 신호를 낼까, 규칙 엔진 + LLM 설명으로 갈까

| 방식 | 설명 | 장점 | 문제 | 판정 |
|---|---|---|---|---|
| (가) LLM 자율 매매 | LLM이 판단하고 도구로 직접 주문 (Alpha Arena식) | 만들기 단순 | Alpha Arena 시즌1에서 6개 중 4개 손실, Claude Sonnet 4.5는 −30~−42%(출처마다 다름, 검색 요약) [S4]. 20년 백테스트(FINSABER)와 누수 방지 평가(2026-08)도 LLM 전략이 운과 구분되지 않는다고 보고(검색 요약) [S5]. 주문 도구를 주면 프롬프트 인젝션이 곧 주문이 된다 (03 §2.3 ⑧) | **기각** |
| (나) LLM이 방향·진입·손절·익절 제안 → 사람 승인 | PLAN v0.1 원안 (PLAN v0.1:26~27) | 사용자의 원래 구상과 같다 | 비전 LLM 방향 적중률이 우연 수준, 롱 편향(롱 82% vs 숏 33%) [S2] [직접]. 숫자 환각. Opus 5.5 학습 데이터 마감이 2026-06이라 과거 백테스트가 무의미하다(학습 데이터를 "기억") [S7] [S6] → **전체 시스템을 과거 데이터로 검증할 수 없다** | **대체** (Q3+F02) |
| (다) 코드 규칙 후보 + Claude 확신도·거부권 관문 | STRATEGY v0.2 §8 "확신도 < 0.6이면 관망", F02(b) 거부권안 | 가격은 코드가 계산 | LLM 확신도는 보정되지 않았다(ECE 0.25~0.58, 검색 요약) [S3]. 검증되지 않은 필터가 표본을 줄이고 선택 편향을 만든다 | **기각** (F02(b), Q11) |
| (라) **코드 규칙 후보 + Claude 설명·반대 근거·의견(섀도) + 코드 메타 필터 기준선** | 코드가 후보·가격·수량을 정하고, Claude는 요약·반대 근거·무효화 조건·의견을 쓴다. 의견은 기록만 하고, 약 600건 비교에서 코드 메타 필터를 이기면 관문으로 승격 | 코드 규칙 전체를 과거 데이터로 검증 가능. 비결정성·환각·거절이 주문에 영향을 주지 않음. 모델 교체 시 코드 트랙 리셋 없음(D21). Claude는 후보가 있을 때만 호출해 월 $10~18(매시 호출하면 $42~73, 추정) (03 요약 5) | Claude의 가치가 "설명"으로 줄어든다. 사용자 원래 구상의 축소라 동의가 필요하다 | **채택 (A4)** — **결정 필요** (D3, §5 #1) |
| (마) 뉴스·경제 일정·거래소 공지를 Claude가 요약해 신규 진입만 차단 (A5) | 코드가 갖지 못한 정보를 Claude가 더한다 | 이론상 엣지 원천 | 프롬프트 인젝션 위험, 뉴스 소스 확보, 법적 검토가 필요 | **고려 → 나중** (G4 이후 "조이는 방향으로만") |

Claude 입력 형태도 같은 논리다. **주입력은 코드가 계산한 수치 JSON**이고, 차트 이미지는 텔레그램에서 사람이 보는 용도다. Claude에게 이미지를 넣을지는 G3 중 "수치만" vs "수치+이미지" 쌍 비교로 정한다("나중") (D4, 03 §2.4.2, Vision 문서 [S11]).

**워뇨띠·차트프로는 이 지형에서 어디에 있나** (02 §2.5.1)
- 워뇨띠: 선을 긋지 않는 가격행동 + 거래량 + 과거 닮은꼴(kNN류) + 지정가·분할 실행과 리스크 관리. 가장 강한 부분은 원장이 보여 주는 **리스크 관리와 지정가 실행**이다. 원장 진입 신호만으로는 제3자 백테스트에서 손실이 났다 (WY REPORT:151).
- 차트프로: 와이코프/VSA("거래량 터진 봉 = 세력 매집") + 볼륨 프로파일("세력가") + SMC식 50%선("허리"). 강의 본문은 확인하지 못했다(자막 0/138, CP REPORT:14).
- 두 방식 모두 **추세추종 필터와 파생 데이터가 빠져 있다**. 그래서 두 사람은 "가설 출처"로 쓰고, 성과 기준은 "무작위 진입 + 같은 리스크 규칙"과 "일봉 돈치안 앙상블"로 둔다 (Q13, D22).

## 7. 검토 방법과 한계

### 7.1 에이전트 팀과 검토 절차

사용자 요청("에이전트 팀을 구성해서")에 따라 역할을 나눴다.

```
[리서처 8명, 병렬]   01 기존 시스템 · 02 차트 분석 방법 · 03 LLM 트레이딩 · 04 거래소·규제
                     05 인프라·운영 · 06 소프트웨어 · 07 텔레그램 승인 · 08 리스크·백테스트
         │  산출: research/planning/01~08
         ▼
[검토자, 관점별]     Q 품질·검증 방법 · SEC 보안 · F 제품·실행 가능성 · A 대안 제안
         ▼
[판정]               지적마다 반박을 시도한 뒤 채택·기각. 결정값 D1~D22, 사용자 결정 10개 확정
         ▼
[문서 작성]          PLAN · ARCHITECTURE · INFRA · SOFTWARE · DEV_GUIDE · SECURITY · PLAN_REVIEW(이 문서)
```

- 앞선 단계(워뇨띠·차트프로 리서처, 전략 종합, 검증자)는 [research/README.md](../research/README.md)에 있다.
- 판정 단계에서 직접 다시 확인한 것: 저장소 공개 여부(GitHub API) [S1], 시간대별 기준봉 분포(1H 데이터 재계산) [S14], 기여도 표본 약 304건(집단당), 괴리 한도 초과 확률 약 55%, 닮은꼴 우연 성립 확률 18.75%.
- 이 문서를 쓰면서 다시 확인한 것: `.gitignore` 내용(4줄), `research/chartpro/raw/details/` 파일 수(138개)와 `author` 필드, `.claude/agents/*.md`의 도구 권한, 인용한 조사 문서의 행 번호.

### 7.2 한계

- 조직 네트워크 정책으로 거래소·텔레그램·ccxt 문서·논문(arxiv 등)·커뮤니티·정부 사이트 대부분을 직접 열 수 없었다. **차단은 우회하지 않았다.** 그런 사실은 "(검색 요약)"으로 표시했다. GitHub·PyPI·Anthropic 공식 문서는 직접 열었다.
- 07·08 리서처는 세션 검색 한도가 소진돼 웹 검색을 하지 못했고, GitHub·PyPI 원문 직접 열람과 데이터 계산으로 대신했다 (07 요약 7, 08 §조사 방법).
- 워뇨띠 A등급 원문(BitMEX 인터뷰·AMA)은 한 건도 직접 읽지 못했고, 차트프로 자막은 0/138건이다 (STRATEGY.md:8~9).
- 08 문서와 판정 단계의 계산은 **현물** 캔들로 한 것이다. 선물 캔들로 다시 계산해야 한다 (Q16).
- 이 검토는 문서 기반이다. 거래소 동작(손절 선배치, countdownCancelAll, 최소 주문 명목 등)은 테스트넷 PoC 전까지 확인 필요다. 목록은 [PLAN.md §11.1](./PLAN.md) C1~C13.
