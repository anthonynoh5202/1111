# 추세추종 규칙 명세서 TREND_SPEC v1.0 (고정)

> 작성일: 2026-09-30 · 상태: **v1.0 고정** (결과를 보기 전에 고정. 바꾸면 v2로 새로 고정하고 `backtest/TRIALS.md`에 기록)
> 배경: 차트프로 규칙(RULES_SPEC v1.0)은 G1에서 16개 조합 모두 판정 보류(6.7년간 실행 가능 거래 29건). 사용자 결정(2026-09-30)으로 **추세추종을 기본 전략**으로, 차트프로식 눌림 진입은 **보조 가설**로 시험한다.
> 재사용: 데이터·체결 엔진·통계는 `backtest/`의 G1 엔진과 같은 규칙(RULES_SPEC §12의 체결·비용·통계)을 따른다. 이 문서에 따로 적은 것만 다르다.
> ⚠️ 오염 고지: 이 전략의 기본형(돈치안 앙상블)은 G1에서 **비교 기준선으로 한 번 결과를 봤다**(연 14.5%, 최대 낙폭 26.9%). 그래서 과거 백테스트는 완전한 검증이 아니며, 진짜 검증은 고정 이후의 모의 운영(G3)이다.

## 0. 한눈에 보기

- **무엇을**: 비트코인이 최근 N일 **최고가를 종가로 넘으면 롱, 최저가를 넘어 내려가면 숏**. 절반 기간의 반대 돌파가 나오면 청산. 기간은 20·55·100일 세 개를 따로 돌려 합친다.
- **언제 신호가 오나**: 일봉 마감(한국 시각 오전 9시) 직후. 사람이 **오전 9시~9시 30분**에 승인한다고 본다.
- **손절**: 진입가에서 **2 × ATR(일봉 20일)** 떨어진 곳에 거래소 손절을 항상 건다.
- **차트프로 보조 시험**: 돌파 신호가 나면 바로 사지 않고, **돌파한 가격까지 되돌아올 때(눌림)** 지정가로 들어가는 방식이 더 나은지 비교한다.

## 1. 신호 (일봉, UTC 00:00 마감)

| 이름 | 정의 |
|---|---|
| N일 상단 U_N | 직전 N개 일봉(당일 제외)의 **종가** 최댓값 |
| N일 하단 D_N | 직전 N개 일봉(당일 제외)의 종가 최솟값 |
| 롱 진입 신호 | 당일 종가 > U_N 이고 해당 하위 시스템이 롱 포지션이 아님 |
| 숏 진입 신호 | 당일 종가 < D_N 이고 해당 하위 시스템이 숏 포지션이 아님 |
| 롱 청산 신호 | 당일 종가 < D_{N/2} (M = N/2, 반올림: 20→10, 55→28, 100→50) |
| 숏 청산 신호 | 당일 종가 > U_{N/2} |
| 반대 신호 | 롱 보유 중 숏 진입 신호가 나오면: 청산 후 같은 시각에 숏 진입(숏도 대칭) |

- 하위 시스템: N ∈ {20, 55, 100}. 각자 독립적으로 포지션을 가진다(한 시스템 안에서는 최대 1포지션).
- 판단 시각: 일봉 마감(00:00 UTC) + 60초. 데이터는 마감된 일봉만.

## 2. 진입·청산 실행

| 항목 | 규칙 |
|---|---|
| 승인 지연 L | 30분 (민감도 10분, 120분). 활성 시각 = 판단 시각 + L |
| 기본 진입 (E0) | 활성 시각 이후 첫 실행 봉 **시가**에 시장가(테이커 0.05% + 슬리피지 0.02%) |
| 보조 진입 (E1, 차트프로 눌림) | 지정가 @ 돌파 레벨(롱 U_N, 숏 D_N), 유효 5일. 관통 체결(메이커 0.02%). 5일 안에 체결 안 되면 그 신호는 거래 없음. 대기 중 청산 신호가 나오면 취소 |
| 보호 손절 | 진입가 ∓ 2 × ATR20(신호 일의 일봉 ATR, RULES_SPEC §3 방식). 체결 즉시 활성. 손절가 체결 + 테이커 0.05% + 슬리피지 0.02%, 갭이면 그 시가 |
| 추세 청산 | 청산 신호의 활성 시각(마감 + 60초 + L) 이후 첫 실행 봉 시가, 테이커 + 슬리피지. 청산은 사람 승인 없이 자동(위험을 줄이는 방향이므로) |
| 펀딩 | RULES_SPEC §12.2와 같음 |
| 실행 봉 | RULES_SPEC §12.1과 같음 (2023-10-01 이후 1분봉, 이전 5분봉) |

## 3. 크기와 R

- **R** = 단위당 순손익 ÷ (진입가와 보호 손절의 거리 + c_stop). G1 판정은 R로 한다(계좌 크기와 무관).
- **계좌 곡선(보고용)**: 하위 시스템마다 1회 위험 r = 0.5% (명목 = R 자본 × 0.005 ÷ 손절 거리 비율, 하위 시스템당 명목 ≤ 0.2배, 합계 ≤ 0.6배). 레버리지 ≤ 3, 격리. 비교용으로 G1 기준선과 같은 "하위 시스템당 명목 0.2배 고정" 곡선도 보고한다.
- PLAN D8의 "손절 폭 ≤ 2%"는 1시간봉 전략용 상한이라 이 전략에는 적용하지 않는다(일봉 2×ATR은 보통 5~10%). 대신 1회 위험 r과 명목 상한으로 위험을 묶는다. (사용자 위임에 따른 결정, 2026-09-30)

## 4. 시험 조합 (시도 수 8)

| 축 | 값 |
|---|---|
| 진입 | E0(돌파 즉시), E1(돌파 레벨 눌림 대기) |
| 방향 | 롱·숏 모두 / 롱만 |
| 하위 시스템 | 앙상블(20·55·100 합산) / 55일 단독 |

8개 조합. 거래 R 통계는 조합 안의 모든 하위 시스템 거래를 합쳐서 계산한다.
민감도(선택에 쓰지 않음): 지연 10·120분, 손절 3 × ATR, 비용 2배.

## 5. 합격 기준 (G1-T, 사전 등록)

RULES_SPEC §8.3의 7개 기준을 그대로 쓴다 (평균 R ≥ +0.15, 부트스트랩 95% 하한 > 0, PF ≥ 1.2, 비용 2배 > 0, 무작위 기준선 95% 분위 초과, 7개 연도 중 4개 이상 양수, 거래 ≥ 30).

- **무작위 기준선**: 같은 조합의 실제 거래와 같은 월별 거래 수·방향 비율로 **무작위 날짜의 일봉 마감**에 진입하고, 같은 보호 손절(그 날의 2 × ATR20)과 같은 추세 청산 규칙(그 방향의 M일 반대 돌파)으로 청산. 1,000회.
- **차트프로 보조 판정**: E1이 E0보다 나은지는 같은 방향·하위 시스템 조합끼리 비교해 **평균 R 차이의 부트스트랩 95% 구간**과 계좌 곡선(연 수익률·최대 낙폭)으로 보고한다. E1이 E0보다 확실히 나을 때만(구간 하한 > 0) 채택 후보.
- 통과한 조합이 여러 개면 **가장 단순한 것**(앙상블보다 단독, 롱·숏보다 롱만, E1보다 E0)을 우선한다. 단, 최대 낙폭이 30%를 넘으면 후순위.
