# 차트 분석 기법 v0.1 — "캔들 + 거래량 + 이평선"

> 작성일: 2026-09-29 · 상태: 초안
> 참고: 워뇨띠 매매 원칙(공개 Q&A·커뮤니티 정리글 기준), 차트프로 유튜브(@chart_pro) 차트 교육 주제
> ⚠️ 워뇨띠 관련 내용은 본인이 직접 쓴 자료가 아니라 **2차 정리글**을 근거로 한다. 원문과 다를 수 있다.

## 1. 참고한 원칙

### 1.1 워뇨띠 (정리글 기준)
| 원칙 | 내용 | 시스템 반영 |
|---|---|---|
| 캔들 + 거래량 위주 | 보조지표보다 캔들 모양과 거래량을 가장 중요하게 본다 | 분석의 1순위 입력 |
| 이평선은 기본 설정 | 이평선은 추세 가늠이나 반등 근거를 찾을 때 보조로 사용한다 | 거래소 기본값 **MA 7 / 25 / 99** |
| 선을 긋지 않음 | 추세선 대신 이평선과 눈대중으로 **지지**를 본다 | 추세선 대신 이평선·전고점·전저점 사용 |
| 장대양봉 + 큰 거래량 | 추세가 이어질 가능성이 있다 | 추세 지속 신호 |
| 고점에서 얇은 캔들 + 큰 거래량, 또는 장대음봉 + 큰 거래량 | 추세가 바뀔 수 있다 | 추세 전환 경고 |
| 여러 시간 단위 | 1분·5분·15분·1시간·4시간·일봉을 모두 본다 | 다중 타임프레임 분석 |
| 시나리오 기반 손절 | 진입할 때 그린 시나리오가 깨지면 1%만 물려 있어도 바로 손절한다 | **무효화 조건**을 필수로 출력 |
| 낮은 실질 레버리지 | 최근에는 전체 자산 기준 약 1배 수준으로 운용 | 레버리지 상한을 낮게 설정 |

### 1.2 차트프로 (채널 교육 주제 기준)
- 핵심 요소: 캔들, 거래량, 추세, 지지·저항, 이평선, 파동
- 대표 기법: **박스권 돌파, 이평선 돌파, 눌림목, 쌍바닥(쌍봉), 전고점 돌파**
- ❓ 영상을 직접 볼 수 없어서 세부 규칙은 아직 반영하지 못했다. 실제로 공부하신 내용(영상 제목, 핵심 규칙)을 알려주면 이 문서에 추가한다.

## 2. 분석 구조: 코드는 측정, Claude는 해석, 규칙은 안전장치

```
[코드] 객관적인 수치 계산 ── 매번 같은 결과, 검증 가능
   │   캔들 크기, 꼬리 비율, 거래량 배수, 이평선 배열, 전고점·전저점 등
   ▼
[Claude] 수치 + 차트 이미지를 보고 맥락 해석 ── 사람처럼 "그림"을 읽음
   │   어떤 시나리오인지, 근거, 무효화 조건, 진입·손절·익절 제안
   ▼
[규칙] 하드 가드 ── AI가 뭐라고 하든 코드가 강제
       손절 없음·손익비 부족·레버리지 초과 → 신호 차단
```

AI에게 전부 맡기지 않고 **수치는 코드가 계산**하는 이유: AI는 숫자 계산에서 실수할 수 있고, 같은 입력에도 답이 달라질 수 있기 때문이다.

## 3. 다중 타임프레임

| 타임프레임 | 역할 | 보는 것 |
|---|---|---|
| 4시간봉 | **큰 방향** | 이평선 배열, 추세 방향 → 롱·숏 중 어느 쪽이 유리한가 |
| 1시간봉 | **신호 발생** (분석 주기) | 캔들 + 거래량 패턴, 지지·저항 |
| 15분봉 | **진입 타이밍** 참고 | 눌림, 돌파 직후 되돌림 |

- 원칙: **큰 방향(4시간)과 반대인 신호는 확신도를 낮추거나 보내지 않는다**
- 1분·5분봉 단타는 제외한다. 사람이 알림을 보고 버튼을 누르기까지 시간이 걸리므로 반자동 구조와 맞지 않는다.

## 4. 코드가 계산하는 수치 (정의)

| 항목 | 정의 (초안) |
|---|---|
| 몸통 크기 | \|종가 − 시가\| |
| 장대봉 | 몸통이 최근 20개 평균 몸통의 **2배 이상** |
| 윗꼬리 / 아래꼬리 비율 | 꼬리 길이 ÷ 전체 캔들 길이(고가 − 저가) |
| 긴 꼬리 | 꼬리 비율 **50% 이상** |
| 거래량 배수 | 현재 거래량 ÷ 최근 20개 평균 거래량 |
| 큰 거래량 | 거래량 배수 **2배 이상** (3배 이상은 "폭발") |
| 이평선 배열 | 정배열: 가격 > MA7 > MA25 > MA99 / 역배열: 반대 |
| 이평선 이격 | (가격 − MA) ÷ MA × 100 (%) |
| 전고점·전저점 | 최근 N개 캔들의 스윙 고점·저점 |
| 박스권 | 최근 N개 캔들의 고가·저가 범위가 좁은 구간 |
| ATR | 평균 변동폭 (손절 폭 계산용) |

숫자(2배, 50%, 20개 등)는 초안이며 백테스트로 조정한다.

## 5. 시그널 시나리오 (초안)

### 롱
| 코드 | 이름 | 조건 (요약) | 근거 |
|---|---|---|---|
| L1 | 추세 지속 | 4시간 정배열 + 1시간 장대양봉 + 큰 거래량 → 이후 눌림에서 진입 | 워뇨띠, 차트프로 눌림목 |
| L2 | 지지 반등 | MA25·MA99 또는 전저점 근처에서 긴 아래꼬리 + 큰 거래량 | 워뇨띠 지지, 차트프로 |
| L3 | 돌파 | 박스권 상단 또는 전고점을 장대양봉 + 큰 거래량으로 돌파 | 차트프로 박스·전고점 돌파 |
| L4 | 쌍바닥 | 비슷한 저점을 두 번 확인한 뒤 거래량을 동반한 반등 | 차트프로 쌍바닥 |

### 숏
| 코드 | 이름 | 조건 (요약) | 근거 |
|---|---|---|---|
| S1 | 고점 전환 | 상승 끝자락에서 긴 윗꼬리(얇은 캔들) + 거래량 급증 | 워뇨띠 |
| S2 | 장대음봉 전환 | 고점권에서 장대음봉 + 큰 거래량 | 워뇨띠 |
| S3 | 지지 이탈 | 박스권 하단, 전저점 또는 MA99를 거래량을 동반해 이탈 | 차트프로 |
| S4 | 쌍봉 | 비슷한 고점에서 두 번 막힌 뒤 거래량을 동반한 하락 | 차트프로 쌍봉 |

### 관망
- 거래량이 적은 횡보, 4시간과 1시간 방향이 충돌, 근거가 약함 → **알림 생략 또는 "관망"으로 표시**

## 6. Claude 출력 형식 (JSON)

```json
{
  "direction": "LONG | SHORT | NEUTRAL",
  "scenario": "L2",
  "confidence": 0.0,
  "summary": "한 줄 요약",
  "evidence": ["근거 1", "근거 2"],
  "entry": 0,
  "stop_loss": 0,
  "take_profit": [0, 0],
  "invalidation": "이 조건이 깨지면 시나리오 무효 (워뇨띠식 손절 기준)",
  "higher_tf_alignment": "4시간봉 방향과 일치 여부"
}
```

- `invalidation`(무효화 조건)은 **필수**다. "그림이 깨지면 손절"이라는 원칙을 코드로 옮긴 것.

## 7. 하드 가드 (코드가 강제)

- 손절가가 없거나 진입가 기준 **최대 손절 폭(예: 2%)**을 넘으면 → 신호 차단
- 손익비(익절 폭 ÷ 손절 폭)가 **1.5 미만**이면 → 신호 차단
- 레버리지 상한 **3배**, 격리 마진
- 확신도 기준(예: 0.6) 미만이면 → 관망 처리

## 8. 검증 계획

1. **백테스트**: 과거 1~2년 데이터로 시나리오별 승률, 손익비, 최대 낙폭을 측정한다. 우선 코드로 판정 가능한 수치 규칙부터 검증한다.
2. **Claude 페이퍼 트레이딩**: 실시간 신호를 기록만 하고 사후 성과를 집계한다.
3. 성과가 나쁜 시나리오는 끄거나 조건을 조정한다.
